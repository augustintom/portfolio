# 🌐 Personal Portfolio Website

## 📖 About the Project

This is my personal portfolio website developed using **HTML** and **CSS**. The portfolio showcases my education, technical skills, projects, certifications, and contact information in a simple and responsive design.

The main purpose of this portfolio is to present my work, skills, and achievements to recruiters, clients, and fellow developers.
